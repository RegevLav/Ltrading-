# Atlas Agents Public Placeholder Site

This folder contains a minimal public site for provider onboarding forms that require:

- Application website
- Terms of Use URL
- Privacy Policy URL
- Redirect URI placeholder

The pages are static HTML and can be hosted with GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static host.

## URLs To Use After Publishing

Replace `https://your-public-site.example` with the real URL from the host.

- Application Website: `https://your-public-site.example/`
- Terms of Use: `https://your-public-site.example/terms.html`
- Privacy Policy: `https://your-public-site.example/privacy.html`
- Redirect URI: `https://your-public-site.example/alpaca-callback.html`

## Fastest Publishing Option

Use Netlify Drop or a similar static hosting tool:

1. Open Netlify Drop in the browser.
2. Drag the `public-site` folder into the page.
3. Copy the generated public URL.
4. Paste the URLs above into Alpaca.

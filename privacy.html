Privacy Policy

Last updated: May 14, 2026

This Privacy Policy describes the intended privacy posture of Atlas Agents, a private paper-trading research application. The current MVP is designed to run locally and avoid collecting public user data.

1. Information Processed Locally

Atlas Agents may store local research data such as assets, strategies, simulated trades, signals, logs, portfolio snapshots, invoices, and provider configuration records. In the local MVP, this data is stored on the operator's own machine or database.

2. API Keys And Credentials

If API keys are configured, they should be stored only in the local environment file or secure secret manager. Users should not paste API secrets into chat, support tickets, screenshots, public repositories, or shared pages.

3. Third-Party Providers

If Atlas Agents is connected to third-party services such as market-data or broker APIs, those providers may process requests, account identifiers, symbols, market-data queries, and other information according to their own privacy policies and terms.

4. No Sale Of Personal Data

The current private MVP does not sell personal data and does not operate an advertising network.

5. Security

The operator should restrict access to the local machine, database, environment files, credentials, and logs. No software system can be guaranteed perfectly secure.

6. Contact

For privacy questions, contact the operator of the private Atlas Agents deployment.

This template is a practical MVP placeholder and should be reviewed by a qualified lawyer before any public launch, third-party user access, OAuth integration, real-money trading, or regulated activity.
